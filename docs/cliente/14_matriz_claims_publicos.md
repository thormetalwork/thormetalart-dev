**Última actualización / Last updated:** 2026-09-11

Esta matriz define qué señales de confianza pueden publicarse. Ningún rating, testimonio, logo o nombre de cliente se considera aprobado por aparecer en una maqueta o dato semilla.

## Criterio de aprobación / Approval Rule

Para publicar prueba social se requiere una fuente verificable, texto o activo aprobado por Karel y fecha de aprobación. Para testimonios se debe conservar además el consentimiento de publicación y el nombre exacto autorizado.

English summary: public social proof requires a verifiable source, client approval, and publication consent. Unverified seed data remains unpublished and recoverable as drafts.
